Status data

Aplikasi akan mengambil harga spot publik dan menyusun candle lokal.

Data spot indikatif bukan kuotasi Exness/MT5. M1–H1 adalah candle hasil pengumpulan data aplikasi, bukan candle historis broker. Saat pertama dibuka, grafik memerlukan waktu untuk terisi.

Batasan aplikasi

  • Hanya menampilkan data dan indikator edukasi.
  • Tidak ada tombol BUY/SELL, order, login, atau koneksi akun broker.
  • Tidak menghasilkan rekomendasi transaksi atau jaminan hasil.
  • Harga diperbarui sesuai ketersediaan penyedia data; jika API gagal, status akan menunjukkan terputus.
